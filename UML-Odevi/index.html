1. UML (Unified Modeling Language) Nedir?

Yazılım Mühendisliğinde Ortak Modelleme Standartları

UML (Birleşik Modelleme Dili); yazılım yoğun sistemlerin mimarisini görselleştirmek, belirtmek (specify), inşa etmek ve belgelemek amacıyla geliştirilmiş uluslararası genel amaçlı modelleme dilidir. 1990'ların ortasında Grady Booch, Ivar Jacobson ve James Rumbaugh ("Üç Amigo") tarafından geliştirilmiş, günümüzde OMG (Object Management Group) bünyesinde ISO standardı olarak yönetilmektedir.

💡 Neden UML Kullanılır?

UML, kodlama başlamadan önce mimarideki mantık ve tasarım hatalarını erkenden yakalayarak teknik borcu (technical debt) minimize eder. Analistler, yazılım mimarları, geliştiriciler ve paydaşlar arasında ortak bir iletişim köprüsü ("Lingua Franca") kurar.

UML 2.5 Diyagramlarının İki Temel Sınıfı

UML 2.5 standardında toplam 14 resmi diyagram bulunur ve iki ana kategoriye ayrılır:

Kategori Açıklama İçerdiği Başlıca Diyagramlar
Yapısal (Structural) Sistemin statik bileşenlerini, sınıflarını ve donanım/yazılım konfigürasyonunu modeller. Zamana bağlı değildir. Class (Sınıf), Object (Nesne), Component (Bileşen), Deployment (Dağıtım), Package (Paket), Composite Structure
Davranışsal (Behavioral) Sistemin çalışma zamanındaki dinamik davranışını, aktör etkileşimlerini ve nesnelerin durum geçişlerini gösterir. Use Case, Activity (Aktivite), State Machine, Etkileşim Diyagramları (Sequence, Communication)

2. Use Case (Kullanım Senaryosu) Diyagramı

Gereksinim Analizi, Sistem Sınırları ve Aktör Etkileşimi

Use Case diyagramları, sistemin dış dünya ile olan işlevsel sınırlarını ve aktörlerin hangi hedeflere ulaşabildiğini gösteren davranışsal diyagramlardır. Sistemin nasıl kodlanacağıyla değil, kullanıcıya ne sunduğuyla ilgilenir.

Temel Bileşenler ve Kurallar

  • Aktör (Actor): Sistemle etkileşime giren insan (Üye, Görevli) veya harici servis (Bildirim Servisi).
  • Use Case (Senaryo): Aktöre ölçülebilir değer üreten eylemler (oval elipsler).
  • Sistem Sınırı (System Boundary): Yazılımın kapsamını belirleyen dikdörtgen çerçeve.
  • <<include>> (Kapsama): Bir senaryonun çalışması için zorunlu ve kaçınılmaz olan alt senaryo (Örn: Ödünç Alma → Üyelik ve Borç Kontrolü).
  • <<extend>> (Genişletme): Yalnızca belirli bir şart sağlandığında devreye giren isteğe bağlı durum (Örn: İade Etme → Gecikme Cezası Hesaplama).

3. ER (Entity-Relationship) Diyagramı

İlişkisel Veri Modeli ve Tablo Şeması

1976 yılında Peter Chen tarafından geliştirilen ER diyagramı, ilişkisel veritabanlarında saklanacak verilerin kavramsal ve mantıksal şemasını tanımlar. Varlıkları (Entity/Tablo), nitelikleri (Attribute/Kolon), birincil anahtarları (PK), yabancı anahtarları (FK) ve kardinalite ilişkilerini (1:1, 1:N, M:N) modeller.

🔑 M:N İlişkilerde Junction Table (Ara Tablo) Çözümü

Bir üye birden fazla kitap ödünç alabilir, bir kitap da zaman içerisinde birçok farklı üyeye ödünç verilebilir (M:N ilişki). İlişkisel veritabanı normalizasyon kuralları gereği bu ilişki ODUNC_ISLEMI ara tablosu ile iki ayrı 1:N ilişkiye bölünmüştür.

4. Class (Sınıf) Diyagramı

OOP Mimarisi, Erişim Belirleyiciler ve İlişki Tipleri

Sınıf diyagramı, yazılımın bellek üzerindeki nesne mimarisini, arayüzlerini (interfaces), sınıfların veri alanlarını, metotlarını ve aralarındaki nesne yönelimli bağları modeller.

OOP İlişki Tipi UML Sembolü Tanım ve Örnek
Inheritance (Kalıtım) <|-- (İçi boş ok) "is-a" ilişkisi. Alt sınıf üst sınıfın alan ve davranışlarını devralır (Örn: Kisi <|-- Uye).
Association (Birliktelik) --> (Düz ok) Sınıflar arası kullanım bağıdır. Örn: OduncKaydi --> Kitap.
Aggregation (Bütünleme) o-- (Boş dörtgen) "has-a" zayıf sahiplik. Parça bağımsız yaşayabilir (Örn: Kutuphane o-- Kitap).
Composition (Bileşim) *-- (Dolu dörtgen) Güçlü sahiplik ve yaşam döngüsü bağımlılığı. Bütün yok edilirse parça da yok olur (Örn: Uye *-- OduncKaydi).

5. C# Nesne Yönelimli Kod Karşılığı

Sınıf Diyagramının Üretime Hazır .NET 8 / C# OOP İmplementasyonu

Aşağıdaki C# kodu, oluşturulan sınıf diyagramındaki tüm soyutlama, kapsülleme, kalıtım ve polimorfizm prensiplerini barındıran modüler bir model dosyasıdır (Dosya: KutuphaneModel.cs).

📄 KutuphaneModel.cs C# 12 / .NET 8 
using System;
using System.Collections.Generic;

namespace KutuphaneOtomasyonu
{
    public enum OduncDurumu { DevamEdiyor, TeslimEdildi, Gecikmede, IptalEdildi }
    public enum UyelikTipi { Ogrenci, Akademisyen, IdariPersonel, Genel }

    public interface IKisi
    {
        int Id { get; }
        string Ad { get; set; }
        string Soyad { get; set; }
        string Eposta { get; set; }
        string Telefon { get; set; }
        string TamAd();
        void BilgiYazdir();
    }

    public abstract class Kisi : IKisi
    {
        private string _ad;
        private string _soyad;
        private string _eposta;

        public int Id { get; protected set; }
        public string Ad { get => _ad; set => _ad = !string.IsNullOrWhiteSpace(value) ? value.Trim() : throw new ArgumentException("Ad boş olamaz."); }
        public string Soyad { get => _soyad; set => _soyad = !string.IsNullOrWhiteSpace(value) ? value.Trim() : throw new ArgumentException("Soyad boş olamaz."); }
        public string Eposta { get => _eposta; set => _eposta = (!string.IsNullOrWhiteSpace(value) && value.Contains("@")) ? value.Trim() : throw new ArgumentException("Geçersiz e-posta."); }
        public string Telefon { get; set; }

        protected Kisi(int id, string ad, string soyad, string eposta, string telefon)
        {
            Id = id; Ad = ad; Soyad = soyad; Eposta = eposta; Telefon = telefon;
        }

        public virtual string TamAd() => $"{Ad} {Soyad}";
        public virtual void BilgiYazdir() => Console.WriteLine($"[ID: {Id}] {TamAd()} | E-posta: {Eposta}");
    }

    public class Uye : Kisi
    {
        public string UyeNo { get; private set; }
        public UyelikTipi Tip { get; set; }
        public decimal ToplamCezaBorcu { get; private set; }
        public List<OduncKaydi> AktifOduncler { get; private set; } = new();

        public Uye(int id, string ad, string soyad, string eposta, string telefon, string uyeNo, UyelikTipi tip)
            : base(id, ad, soyad, eposta, telefon)
        {
            UyeNo = uyeNo; Tip = tip;
        }

        public int MaksimumKitapLimiti() => Tip switch
        {
            UyelikTipi.Akademisyen => 10,
            UyelikTipi.Ogrenci => 5,
            _ => 3
        };

        public bool OduncAlabilirMi() => ToplamCezaBorcu <= 50.0m && AktifOduncler.Count < MaksimumKitapLimiti();
        public void CezaEkle(decimal tutar) { if (tutar > 0) ToplamCezaBorcu += tutar; }
    }

    public class Kitap
    {
        public int KitapId { get; private set; }
        public string ISBN { get; private set; }
        public string Baslik { get; set; }
        public string Yazar { get; set; }
        public int StokAdedi { get; private set; }

        public Kitap(int id, string isbn, string baslik, string yazar, int stok)
        {
            KitapId = id; ISBN = isbn; Baslik = baslik; Yazar = yazar; StokAdedi = Math.Max(0, stok);
        }

        public bool OduncVerilebilirMi() => StokAdedi > 0;
        public void StokAzalt() { if (StokAdedi <= 0) throw new InvalidOperationException("Stok yok!"); StokAdedi--; }
        public void StokArtir() => StokAdedi++;
    }

    public class OduncKaydi
    {
        public Guid IslemId { get; private set; } = Guid.NewGuid();
        public Uye Uye { get; private set; }
        public Kitap Kitap { get; private set; }
        public DateTime OduncTarihi { get; private set; } = DateTime.Now;
        public DateTime SonTeslimTarihi { get; private set; }
        public DateTime? TeslimTarihi { get; private set; }
        public OduncDurumu Durum { get; private set; } = OduncDurumu.DevamEdiyor;
        public decimal CezaTutari { get; private set; }

        public OduncKaydi(Uye uye, Kitap kitap, int gun = 15)
        {
            Uye = uye; Kitap = kitap; SonTeslimTarihi = OduncTarihi.AddDays(gun);
        }

        public void IslemiKapat(DateTime teslimTarihi)
        {
            TeslimTarihi = teslimTarihi;
            if (teslimTarihi > SonTeslimTarihi)
            {
                int gun = (int)Math.Ceiling((teslimTarihi - SonTeslimTarihi).TotalDays);
                CezaTutari = gun * 5.0m;
                Durum = OduncDurumu.Gecikmede;
                Uye.CezaEkle(CezaTutari);
            }
            else { Durum = OduncDurumu.TeslimEdildi; }
            Kitap.StokArtir();
            Uye.AktifOduncler.Remove(this);
        }
    }
}
