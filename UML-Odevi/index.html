1. UML (Unified Modeling Language) Nedir?

UML (Birleşik Modelleme Dili), yazılım sistemlerinin analizini, tasarımını ve belgelenmesini standart hale getirmek için kullanılan görsel bir modelleme dilidir. Kod yazmaya başlamadan önce sistemin yapısını haritalandırmamızı sağlar. 1990'ların ortasında Grady Booch, Ivar Jacobson ve James Rumbaugh tarafından ortaya konulmuş ve OMG (Object Management Group) tarafından resmi bir standart haline getirilmiştir.

Neden UML Kullanıyoruz?: Bir projeye doğrudan kod yazarak başlamak, plansız bir inşaata başlamaya benzer. UML diyagramları sayesinde gereksinimleri erkenden görebilir, veritabanı tablolarımızı ve sınıflar arasındaki ilişkileri baştan planlayarak tasarım hatalarını erkenden fark edebiliriz.

UML Diyagramlarının Sınıflandırılması

UML 2.5 standardında toplam 14 diyagram türü yer alır ve temel olarak iki ana gruba ayrılır:

  • Yapısal (Statik) Diyagramlar: Sistemin değişmeyen statik bileşenlerini ve sınıflarını gösterir. Örneğin: Class (Sınıf) Diyagramı, Object (Nesne) Diyagramı, Component Diyagramı.
  • Davranışsal (Dinamik) Diyagramlar: Sistemin zaman içindeki işleyişini, aktörlerle etkileşimini ve nesnelerin durumlarını gösterir. Örneğin: Use Case (Kullanım Senaryosu) Diyagramı, Activity Diyagramı, Sequence Diyagramı.

2. Use Case (Kullanım Senaryosu) Diyagramı

Use Case diyagramı, kullanıcıların (aktörlerin) sistem üzerinden hangi işlevleri gerçekleştirebileceğini yüksek seviyede gösteren davranışsal bir diyagramdır. Sistemin iç kod detaylarıyla değil, dışarıdan bakıldığında ne iş yaptığıyla ilgilenir.

Temel Kavramlar:

  • Aktör (Actor): Sistemle etkileşime geçen kişi veya harici servislerdir (Örn: Üye, Kütüphaneci, SMS Servisi).
  • Use Case (Senaryo): Sistemin sunduğu bir fonksiyon veya hedeftir (Örn: Kitap Ödünç Al).
  • <<include>> (Kapsama): Bir senaryo çalıştığında çalışması zorunlu olan alt senaryodur. Örneğin kitap ödünç alınırken her seferinde üyenin ceza ve limit kontrolünün yapılması zorunludur.
  • <<extend>> (Genişletme): Belirli bir koşul gerçekleştiğinde devreye giren isteğe bağlı durumdur. Örneğin kitap iade edilirken süre aşılmışsa gecikme cezası hesaplanması extend ilişkisidir.

3. ER (Entity-Relationship) Diyagramı

ER diyagramı (Varlık-İlişki Modeli), Peter Chen tarafından 1976 yılında geliştirilmiş bir veritabanı modelleme tekniğidir. Veritabanında saklayacağımız varlıkları (tabloları), bu varlıkların niteliklerini (kolonlarını) ve tablolar arasındaki ilişkileri gösterir.

Veritabanı Yapısı ve İlişkiler:

  • 1:N (Bire-Çok) İlişki: Bir kategoride birden fazla kitap bulunabilir (Kategori → Kitap).
  • M:N (Çoka-Çok) İlişki ve Ara Tablo: Bir üye birçok kitap ödünç alabilir, bir kitap da farklı zamanlarda birçok üyeye verilebilir. İlişkisel veritabanında bu çoka-çok ilişkiyi yönetebilmek için ODUNC_ISLEMI adında bir ara tablo (junction table) oluşturulur. Böylece iki adet 1:N ilişki kurulmuş olur.

4. Class (Sınıf) Diyagramı

Class diyagramı, Nesne Yönelimli Programlamanın (OOP) temel yapı taşıdır. Yazılımın bellekte nasıl çalışacağını, sınıfların alanlarını (properties), metotlarını ve aralarındaki kalıtım/birliktelik bağlarını modeller.

UML Erişim Belirteçleri ve OOP Kavramları:

  • + (Public): Her yerden erişilebilir.
  • - (Private): Yalnızca tanımlandığı sınıf içerisinden erişilebilir (Kapsülleme).
  • # (Protected): Sınıfın kendisi ve ondan türeyen alt sınıflar erişebilir.
  • Kalıtım (Inheritance): Kisi soyut sınıfından Uye ve Kutuphaneci sınıfları türetilmiştir.
  • Bütünleme (Aggregation): Kütüphane sınıfı kitapları barındırır, ancak kütüphane kapansa da kitap varlığını korur (o--).
  • Bileşim (Composition): Üye ile ödünç kaydı arasındaki sıkı sahiplik ilişkisidir (*--).

5. C# Nesne Yönelimli Kod Karşılığı (KutuphaneModel.cs)

Yukarıda tasarladığım sınıf diyagramını C# dilinde nesne yönelimli programlama prensiplerine uygun olarak kodladım. Kod içerisinde abstract class, interface, inheritance ve kapsülleme mekanizmaları kullanılmıştır.

KutuphaneModel.cs (C# OOP Kodu) 
using System;
using System.Collections.Generic;

namespace KutuphaneOtomasyonu
{
    // Temel enum tanımları
    public enum OduncDurumu { DevamEdiyor, TeslimEdildi, Gecikmede, IptalEdildi }
    public enum UyelikTipi { Ogrenci, Akademisyen, IdariPersonel, Genel }

    // Kişi arayüzü
    public interface IKisi
    {
        int Id { get; }
        string Ad { get; set; }
        string Soyad { get; set; }
        string Eposta { get; set; }
        string Telefon { get; set; }
        string TamAd();
        void BilgiYazdir();
    }

    // Soyut Kisi Temel Sınıfı (Abstract Class)
    public abstract class Kisi : IKisi
    {
        private string _ad;
        private string _soyad;
        private string _eposta;

        public int Id { get; protected set; }

        public string Ad
        {
            get => _ad;
            set => _ad = !string.IsNullOrWhiteSpace(value) ? value.Trim() : throw new ArgumentException("Ad boş bırakılamaz.");
        }

        public string Soyad
        {
            get => _soyad;
            set => _soyad = !string.IsNullOrWhiteSpace(value) ? value.Trim() : throw new ArgumentException("Soyad boş bırakılamaz.");
        }

        public string Eposta
        {
            get => _eposta;
            set => _eposta = (!string.IsNullOrWhiteSpace(value) && value.Contains("@")) ? value.Trim() : throw new ArgumentException("Geçersiz e-posta.");
        }

        public string Telefon { get; set; }

        protected Kisi(int id, string ad, string soyad, string eposta, string telefon)
        {
            Id = id; Ad = ad; Soyad = soyad; Eposta = eposta; Telefon = telefon;
        }

        public virtual string TamAd() => $"{Ad} {Soyad}";
        public virtual void BilgiYazdir() => Console.WriteLine($"[ID: {Id}] {TamAd()} | E-posta: {Eposta}");
    }

    // Üye Sınıfı (Kalıtım: Kisi'den türetildi)
    public class Uye : Kisi
    {
        public string UyeNo { get; private set; }
        public UyelikTipi Tip { get; set; }
        public DateTime UyelikTarihi { get; private set; }
        public bool AktifMi { get; set; }
        public decimal ToplamCezaBorcu { get; private set; }
        public List<OduncKaydi> AktifOduncler { get; private set; } = new();

        public Uye(int id, string ad, string soyad, string eposta, string telefon, string uyeNo, UyelikTipi tip)
            : base(id, ad, soyad, eposta, telefon)
        {
            UyeNo = uyeNo;
            Tip = tip;
            UyelikTarihi = DateTime.Now;
            AktifMi = true;
        }

        public int MaksimumKitapLimiti() => Tip switch
        {
            UyelikTipi.Akademisyen => 10,
            UyelikTipi.Ogrenci => 5,
            _ => 3
        };

        public bool OduncAlabilirMi() => AktifMi && ToplamCezaBorcu <= 50.0m && AktifOduncler.Count < MaksimumKitapLimiti();
        public void CezaEkle(decimal tutar) { if (tutar > 0) ToplamCezaBorcu += tutar; }
        public void CezaOde(decimal tutar) { if (tutar > 0) ToplamCezaBorcu = Math.Max(0, ToplamCezaBorcu - tutar); }
    }

    // Kütüphaneci Personel Sınıfı
    public class Kutuphaneci : Kisi
    {
        public string PersonelKodu { get; private set; }
        public string Unvan { get; set; }
        public int YetkiSeviyesi { get; set; }

        public Kutuphaneci(int id, string ad, string soyad, string eposta, string telefon, string personelKodu, string unvan, int yetki = 1)
            : base(id, ad, soyad, eposta, telefon)
        {
            PersonelKodu = personelKodu;
            Unvan = unvan;
            YetkiSeviyesi = yetki;
        }

        public Kitap YeniKitapKaydet(string isbn, string baslik, string yazar, int yayinYili, int stok, Kategori kategori)
        {
            return new Kitap(new Random().Next(1000, 9999), isbn, baslik, yazar, yayinYili, stok, kategori);
        }
    }

    // Kategori Sınıfı
    public class Kategori
    {
        public int KategoriId { get; set; }
        public string Ad { get; set; }
        public string Aciklama { get; set; }

        public Kategori(int id, string ad, string aciklama = "")
        {
            KategoriId = id; Ad = ad; Aciklama = aciklama;
        }
    }

    // Kitap Sınıfı
    public class Kitap
    {
        public int KitapId { get; private set; }
        public string ISBN { get; private set; }
        public string Baslik { get; set; }
        public string Yazar { get; set; }
        public int YayinYili { get; set; }
        public int StokAdedi { get; private set; }
        public Kategori Kategori { get; set; }

        public Kitap(int id, string isbn, string baslik, string yazar, int yayinYili, int stok, Kategori kategori)
        {
            KitapId = id; ISBN = isbn; Baslik = baslik; Yazar = yazar; YayinYili = yayinYili;
            StokAdedi = Math.Max(0, stok); Kategori = kategori;
        }

        public bool OduncVerilebilirMi() => StokAdedi > 0;
        public void StokAzalt() { if (StokAdedi <= 0) throw new InvalidOperationException("Stok bitti."); StokAdedi--; }
        public void StokArtir() => StokAdedi++;
    }

    // Ödünç Kaydı Sınıfı (Junction Model)
    public class OduncKaydi
    {
        public Guid IslemId { get; private set; } = Guid.NewGuid();
        public Uye Uye { get; private set; }
        public Kitap Kitap { get; private set; }
        public DateTime OduncTarihi { get; private set; } = DateTime.Now;
        public DateTime SonTeslimTarihi { get; private set; }
        public DateTime? TeslimTarihi { get; private set; }
        public OduncDurumu Durum { get; private set; } = OduncDurumu.DevamEdiyor;
        public decimal CezaTutari { get; private set; }
        public const decimal GunlukGecikmeCezasi = 5.0m;

        public OduncKaydi(Uye uye, Kitap kitap, int gun = 15)
        {
            Uye = uye; Kitap = kitap; SonTeslimTarihi = OduncTarihi.AddDays(gun);
        }

        public void IslemiKapat(DateTime teslimTarihi)
        {
            TeslimTarihi = teslimTarihi;
            if (teslimTarihi > SonTeslimTarihi)
            {
                int gecikenGun = (int)Math.Ceiling((teslimTarihi - SonTeslimTarihi).TotalDays);
                CezaTutari = gecikenGun * GunlukGecikmeCezasi;
                Durum = OduncDurumu.Gecikmede;
                Uye.CezaEkle(CezaTutari);
            }
            else
            {
                Durum = OduncDurumu.TeslimEdildi;
            }
            Kitap.StokArtir();
            Uye.AktifOduncler.Remove(this);
        }
    }
}
